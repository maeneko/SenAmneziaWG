# Каталог ошибок

Каждая ошибка, которую видит человек, получает код `ОБЛ-NN` и один текст. Код одинаков в SenAWG и SenAWG для Android.
Текст можно менять, код — нет; выведенный код больше никому не выдаётся.

**Статус.** Коды стабильны — их можно переносить как есть (в SenAWG для Android, на страницу `/errors` сайта).
Источник — `src/shared/errorCatalog.ts`; если этот документ с ним расходится, прав файл. Тексты пока черновые:
построчно не вычитаны, мелкие правки возможны.

Пути в таблицах:
- **Десктоп** — от `src/` (`main/…`, `renderer/…`, `shared/…`) и `helper/`;
- **Android** — от `app/src/main/kotlin/org/maeneko/senawg/` и `engine/` (репозиторий senawg-android).

## Правила

1. Текст — «что случилось — что делать». Вторая часть есть, только если человек может что-то сделать.
2. Виновник называется всегда одинаково: *сервер ключа*, *сервер обновлений*, *MA7*, *служба SenAWG*, *Android*.
3. Локальная беда не выдаётся за ответ сервера.
4. Подробности (HTTP-код, `ECONNRESET`, текст исключения, имя поля) — только в журнал, строкой `[КОД] подробности`.
   Исключение: где подробность помогает исправить ввод (имя правила, поле конфига) — в `{скобках}` шаблона.
5. Глаголы: «переустановите SenAWG», «обновите SenAWG», «отключитесь от VPN», «скопируйте ссылку заново».
6. Подсказки под полями ввода (правила маршрутизации, ключ в поле импорта) показываются без кода; код — в журнале.
7. Всё, чего нет в каталоге, — `ERR-00` с исходным текстом в журнале.
