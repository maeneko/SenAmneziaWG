Обновление на macOS

Откройте «Настройки → Приложение», нажмите «Проверить обновления», затем «Скачать» и «Перезапустить и обновить». Всё, что происходит в системе, — ниже.

  1. Сайт: GET /api/page/downloads/macos — есть версия новее
  2. Скачивается SenAWG--arm64.dmg, в конце образа — трейлер koly
  3. Образ монтируется, внутри проверяются id и версия, ditto копирует приложение рядом: .SenAWG-.app. Старая версия пока работает
  4. Приложение закрывается. Скрипт узнаёт об этом по закрывшемуся каналу и меняет копии местами двумя переименованиями
  5. open -n открывает новую копию на месте старого окна
  6. «Обновлено до …», подключение восстанавливается (на macOS — с паролем администратора)
